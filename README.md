# BusinessPerformanceDashboard

A modern, responsive, and interactive **Restaurant Business Performance Dashboard** built using **HTML, CSS, and JavaScript**. This frontend-only project visualizes restaurant business metrics through clean UI components and interactive charts, making it ideal for learning dashboard design and frontend development.

---

## 📌 Overview

The Restaurant Business Performance Dashboard provides an intuitive interface for monitoring key restaurant metrics such as revenue, orders, customer activity, inventory, and menu performance.

This project focuses purely on frontend development using static sample data and requires no backend or database.
